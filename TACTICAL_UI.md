# Operator dashboard

The former event-derived tactical/radar view has been replaced with a restrained
image-space monitoring console. No radar position is inferred from event prose.

See README.md for the architecture and DEMO_RUNBOOK.md for source modes, replay,
reset, source provenance and failure recovery. Existing ingestion, SQLite data,
Viso connector and the independent `demo_feed.py` helper remain in place.
