# Hosted static demo

This folder is what GitHub Pages serves. `index.html` is `preview.html` with a small `fetch()` shim at the top of `<head>`; `api/` holds the tracker's recorded output (`GET /api/preview/tracks`) for every scenario, contact count and sensor-loss mode at seed 42, generated by calling the real `dronewatch.api.preview.get_tracks` once per combination. Nothing is computed in the browser that the Python tracker did not compute first.

Not available statically: the Monte Carlo containment cloud for a selected lost track (`/api/preview/paths`), camera clips, and live Viso webhook evidence. Run the server (see the top-level README) for those.

Regenerate after a tracker change:

```bash
python3 scripts/build_site.py
```
